# BindPad Enhanced

Keybinding pad for World of Warcraft 3.3.5a (WotLK): drag spells, items and macros into BindPad's slots and click a slot to bind a key. Open it with `/bindpad` or `/bp`.

Based on **BindPad** by **Tageshi**. All credit for the original addon goes to its author.

## What this version does differently

- **Export / Import:** turn a profile into a text string you can copy, and paste it back on another profile or character (`/bp export`, `/bp import`, or the buttons in the window). It asks before overwriting.
- **Copy profile:** copy every slot and binding of a profile, or of a single tab, into another one (`/bp copy`).
- Lower memory use and a few bug fixes.

## Installation

1. Download this repository (**Code → Download ZIP**).
2. Copy the `BindPad` folder into `World of Warcraft/Interface/AddOns/`.
